# Channels for `mimus calibrate` to observe.
#
# Not the same thing as the record list. QSRV2 serves every record *field*
# as a channel of its own, and some PVA type codes are only reachable that
# way - no base record carries an unsigned VAL, for instance.
#
# Two channels per type throughout: calibration templates the opening
# message of a type by comparing the opening messages of its channels, and a
# second channel shows whether the server sends the type descriptor again or
# only a reference to it.
#
# Order matters. Calibration builds one template per type, from the first
# channel of that type in this list, so each type lists a moving channel
# before its static ones, and the strings list the variable-length
# MIM:STRV:* first. A type whose channels are all static is templated as
# static.

# --- field channels ----------------------------------------------------
#
# QSRV2 serves each record field as an NTScalar channel typed after the
# field:  .RVAL -> uint32_t   .PREC -> int16_t   .UDF -> uint8_t
#
# uint32, moving: MIM:MBBI:* use Raw Soft Channel, so RVAL follows the input.
MIM:MBBI:0.RVAL
MIM:MBBI:1.RVAL
# uint32, static: MIM:BI:* use Soft Channel, which leaves RVAL alone.
MIM:BI:0.RVAL
MIM:BI:1.RVAL
# int16 and uint8, static: after MIM:I16:* and MIM:U8:* above.
MIM:F64:0.PREC
MIM:F64:1.PREC
MIM:F64:0.UDF
MIM:F64:1.UDF
